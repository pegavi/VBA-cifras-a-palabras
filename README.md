# VBA-cifras-a-palabras
Complemento para Microsoft Word que convierte un número expresado en cifras en su expresión cardinal (palabras)

# Como instalar

1. Descarga el archivo CifrasEnLetras.bas

2. En cualquier archivo de Word, buscar la pestaña "Programador"
![image](https://github.com/user-attachments/assets/129316dd-7f3b-414d-95b2-c86aea8e3d5e)

Si la pestaña "Programador" no está disponible, es necesario activarla previamente.

Ir a Archivo > Opciones > Personalizar Cinta de Opciones
En la columna de la derecha, buscar la casilla "Programador" y activarla

![image](https://github.com/user-attachments/assets/590279c9-b3d8-4b62-9d51-fdf1a258f19e)

3. Una vez en la pestaña "Programador", haz click en el botón Visual Basic o pulsa Alt + F11.

4. Arrastra el archivo CifrasEnLetras.bas hasta la zona de Proyectos, y suéltalo **sobre "Normal"**. Así, el programa será accesible desde cualquier documento de Word. Si lo pones en otro proyecto, sólo será accesible desde ese documento.
   
![image](https://github.com/user-attachments/assets/559e6975-8952-4113-b758-5144914dd885)

5. Antes de cerrar, dale al icono de guardar documento.

![image](https://github.com/user-attachments/assets/d18eef79-71ec-4022-aca4-0b2e27c3b645)

   
6. Ya puedes cerrar el editor de VBA y el documento Word. El programa debería ser accesible pulsando Alt + F8 o desde la pestaña "Programador", botón "Macros". Puedes asignarle un atajo de teclado predefinido para mayor comodidad.
